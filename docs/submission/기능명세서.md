# TaskFlow 기능명세서

## 1. 문서 개요

각 기능의 **입력 → 처리 → 출력** 과 **화면/동작 흐름** 을 기술한다. 모든 처리 단계는 실제 코드의
파일 경로·함수명을 근거로 적었으며, 명세는 현재 구현과 일치한다.

### 1.1 공통 동작 원리

- **읽기**: React Server Component / Server Action 으로 Supabase에서 조회
- **쓰기(앱 내부)**: `"use server"` Server Action — Zod 검증 후 DB 반영, 경로 재검증(`revalidatePath`)
- **외부 연동**: Route Handler(`src/app/api/**`) — 웹훅·AI·STT
- **실시간 반영**: Supabase Postgres CDC 구독(`use-board-realtime.ts`) → 디바운스 후 새로고침
- **낙관적 UI**: Zustand 스토어(`entities/board/model/store.ts`)에 먼저 반영, 실패 시 스냅샷 복원
- **정렬**: LexoRank 문자열(`shared/lib/lexorank.ts`)로 인접 두 항목만 계산해 위치 부여

**기능**: 이메일/OAuth 로그인·회원가입.

| 구분 | 내용 |

## 12. 테스트로 검증한 핵심 로직

`tests/` 의 단위 테스트 17개 파일이 전부 통과(`npm test`)하며, 다음을 검증한다:
LexoRank 정렬, 카드 이동 충돌 감지, AI 분류 로직(마감일 가산·담당자 매칭), PR 상태 전이,
GitHub 서명 검증, 회의 요약 파싱, 카드 필터, 멤버 권한(마지막 owner 보호).

## 4. 팀 회고

### 잘한 점
- 기능 요구사항(FR) 27개를 거의 다 만들었다.
- AI, 실시간 협업, GitHub 연동을 실제로 동작하게 했다.
- 테스트 17개 파일(162개)을 전부 통과시켜서 중요한 기능이 안 깨지게 했다.
- 설계 때 발표한 디자인 패턴 4개를 코드에 실제로 적용했다.

### 어려웠던 점 (실제로 겪은 문제 — `docs/solutions/`에 기록)
1. **GitHub 웹훅이 같은 일을 여러 번 처리**해서 카드가 잘못 옮겨졌다. 중복을 막는 처리로 해결했다.
2. 데이터베이스에 관계(FK)를 추가했더니 **기존 조회 쿼리가 깨졌다**(PGRST201). 관계를 명확히 지정해서 고쳤다.
3. PR 웹훅이 엉뚱한 이벤트에서 **카드 배지를 덮어쓰는** 문제가 있었다.
4. 서버에서 에러를 그냥 던졌더니 **화면 전체가 에러로 덮였다**. 에러 대신 결과를 돌려주는 방식으로 고쳤다.

### 더 하고 싶은 것
- 컬럼 드래그 순서변경 화면 마무리, OAuth 로그인 주소 등록.
- 성능·테스트 커버리지 숫자로 측정하기.
- 실제 배포·자동 백업, E2E 테스트 추가.
